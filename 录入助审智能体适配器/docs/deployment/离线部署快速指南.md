# 北交所录入助审系统 - 离线部署快速指南

## 📦 适用场景

本指南适用于**无法访问互联网的内网环境**，需要通过离线方式部署系统。

## 🎯 部署流程概览

```
[有网络环境] → 构建镜像 → 导出tar包 → [传输] → [内网环境] → 导入镜像 → 运行容器
```

---

## 第一部分：准备工作（有网络的机器上）

### 1. 获取项目代码

```bash
git clone https://gitee.com/momomomom/bjs_luruzhushen.git
cd bjs_luruzhushen
```

### 2. 构建和导出Docker镜像

**Linux/Mac系统：**

```bash
# 赋予脚本执行权限
chmod +x scripts/docker_build_and_export.sh

# 执行构建和导出
./scripts/docker_build_and_export.sh
```

**Windows系统（PowerShell）：**

```powershell
# 执行PowerShell脚本
.\scripts\docker_build_and_export.ps1
```

**手动执行（任何系统）：**

```bash
# 1. 构建镜像
docker build -t bjs-luruzhushen:latest .

# 2. 导出镜像
mkdir -p docker-export
docker save -o docker-export/bjs-luruzhushen-latest.tar bjs-luruzhushen:latest

# 3. 压缩（可选）
cd docker-export
tar -czf bjs-luruzhushen-latest.tar.gz bjs-luruzhushen-latest.tar
cd ..
```

### 3. 准备部署包

将以下文件打包：

```
离线部署包/
├── bjs-luruzhushen-latest.tar.gz  (或 .tar)  # Docker镜像
├── scripts/
│   └── docker_deploy.sh              # 部署脚本
├── docker-compose.yml                # Docker Compose配置（可选）
└── 离线部署快速指南.md              # 本文档
```

## 第二部分：离线部署（目标服务器上）

### 前置要求

确保目标服务器已安装：

- ✅ Docker 20.10+
- ✅ 至少 8GB 内存
- ✅ 至少 10GB 可用磁盘空间

检查Docker安装：

```bash
# 检查Docker版本
docker --version

# 检查Docker服务状态
docker info

# 如果Docker未启动，启动服务
sudo systemctl start docker
sudo systemctl enable docker
```

### 方式1：使用部署脚本（推荐）⭐

```bash
# 1. 上传部署包到服务器并解压
tar -xzf bjs-luruzhushen-deploy.tar.gz
cd bjs-luruzhushen-deploy

# 2. 赋予脚本执行权限
chmod +x scripts/docker_deploy.sh

# 3. 执行部署脚本
./scripts/docker_deploy.sh
```

脚本会自动完成：
- ✅ 导入Docker镜像
- ✅ 清理旧容器（如果存在）
- ✅ 创建数据目录
- ✅ 启动新容器
- ✅ 执行健康检查

### 方式2：手动部署

#### 步骤1：导入镜像

```bash
# 如果是压缩文件，先解压
tar -xzf bjs-luruzhushen-latest.tar.gz

# 导入镜像到Docker
docker load -i bjs-luruzhushen-latest.tar

# 验证镜像已导入
docker images | grep bjs-luruzhushen
```

#### 步骤2：创建数据目录

```bash
mkdir -p logs data/uploads data/temp
```

#### 步骤3：启动容器

```bash
docker run -d \
  --name bjs-luruzhushen-app \
  -p 8580:8580 \
  -v $(pwd)/logs:/app/logs \
  -v $(pwd)/data/uploads:/app/data/uploads \
  -v $(pwd)/data/temp:/app/data/temp \
  -e HOST=0.0.0.0 \
  -e PORT=8580 \
  -e DEBUG=false \
  -e LOG_LEVEL=INFO \
  --restart unless-stopped \
  bjs-luruzhushen:latest
```

#### 步骤4：验证部署

```bash
# 检查容器状态
docker ps | grep bjs-luruzhushen

# 查看容器日志
docker logs -f bjs-luruzhushen-app

# 测试服务健康
curl http://localhost:8580/health
```

## 第四部分：日常管理

### 容器管理命令

```bash
# 查看容器状态
docker ps

# 查看日志（实时）
docker logs -f bjs-luruzhushen-app

# 查看最近100行日志
docker logs --tail 100 bjs-luruzhushen-app

# 停止容器
docker stop bjs-luruzhushen-app

# 启动容器
docker start bjs-luruzhushen-app

# 重启容器
docker restart bjs-luruzhushen-app

# 进入容器
docker exec -it bjs-luruzhushen-app /bin/bash
```

### 日志查看


## 第五部分：配置调整

### 修改端口

如果8580端口被占用，修改启动命令：

```bash
docker run -d \
  --name bjs-luruzhushen-app \
  -p 9000:8580 \        # 改为9000端口
  ...
```

### 开启调试模式

```bash
docker run -d \
  --name bjs-luruzhushen-app \
  -p 8580:8580 \
  -e DEBUG=true \       # 开启调试
  -e LOG_LEVEL=DEBUG \  # 详细日志
  ...
```

### 设置资源限制

```bash
docker run -d \
  --name bjs-luruzhushen-app \
  --memory="2g" \       # 限制内存2GB
  --cpus="2" \          # 限制CPU 2核
  -p 8580:8580 \
  ...
```

## ❓ 常见问题排查

### 问题1：容器启动后立即停止

```bash
# 查看容器日志找原因
docker logs bjs-luruzhushen-app

# 常见原因：
# - 端口被占用
# - 权限不足
# - 内存不足
```

### 问题2：无法访问服务

```bash
# 1. 检查容器是否运行
docker ps | grep bjs-luruzhushen

# 2. 检查端口映射
docker port bjs-luruzhushen-app

# 3. 检查防火墙
sudo firewall-cmd --list-ports
sudo firewall-cmd --add-port=8580/tcp --permanent
sudo firewall-cmd --reload

# 4. 测试本地访问
curl http://localhost:8580/health
```

### 问题3：镜像导入失败

```bash
# 检查磁盘空间
df -h

# 检查文件完整性
md5sum bjs-luruzhushen-latest.tar

# 清理Docker空间
docker system prune -a
```

### 问题4：内存不足

```bash
# 增加容器内存限制
docker run --memory="4g" ...

# 或调整交换空间
sudo swapon --show
```

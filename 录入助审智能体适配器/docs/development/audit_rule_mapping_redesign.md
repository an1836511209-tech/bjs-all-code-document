# 审核规则数据映射重新设计

## 概述

本次重新设计了审核规则的数据映射机制，支持两种映射方式：**自动映射**和**自定义映射**，以满足不同的审核场景需求。

## 核心概念

### 1. 审核规则类型

- **字段审核**：针对字段值进行审核，比较系统字段值与附件材料中提取的值
- **文件审核**：针对文件/附件内容进行审核

### 2. 数据映射类型（仅字段审核适用）

#### 自动映射（默认）
- **适用场景**：提取和审核是一对一对应关系
- **工作原理**：
  1. 选择一个已有的提取规则字段名
  2. 系统自动获取该提取规则配置的所有参考材料
  3. 自动映射这些材料中提取的字段值
  4. 可选包含用户在表单系统中手工填写的数据
- **优点**：配置简单，只需填写审核内容和处理规则

#### 自定义映射
- **适用场景**：需要灵活审核，不限于单一字段
- **工作原理**：手动配置每个审核数据源，包括材料名称、字段名称或全文
- **优点**：灵活度高，支持复杂审核逻辑

### 3. 审核数据源（AuditDataSource）

自定义映射或文件审核时使用，配置格式：

```python
{
    "material_name": "《信息披露申请书》",  # 材料名称
    "field_name": "转让方名称",             # 字段名称，留空或"全文"表示获取整个材料
    "description": "从申请书中提取转让方"    # 说明（选填）
}
```

## 数据结构

### AuditRule 模型

```python
class AuditRule(BaseModel):
    id: str
    audit_type: AuditType  # 字段审核 / 文件审核
    field_name: str        # 审核字段/文件名称
    
    # 字段审核配置（仅字段审核时有效）
    mapping_type: Optional[MappingType]     # auto / manual
    source_field_name: Optional[str]        # 源字段名称（自动映射时）
    include_user_input: bool = True         # 是否包含用户表单数据
    
    # 审核数据源（自定义映射或文件审核时使用）
    audit_data_sources: Optional[List[AuditDataSource]]
    
    # 审核规则配置
    audit_content: str              # 审核内容描述
    auto_process_rules: str         # 自动处理规则
    
    # 元数据
    enabled: bool
    created_at: datetime
    updated_at: datetime
    notes: Optional[str]
```

## 使用示例

### 示例 1：字段审核 + 自动映射

审核"转让方名称"，自动从提取规则获取所有参考材料的结果：

```json
{
    "audit_type": "字段审核",
    "field_name": "转让方名称",
    "mapping_type": "auto",
    "source_field_name": "转让方名称",
    "include_user_input": true,
    "audit_content": "转让方类型需与转让方名称体现的类型一致；且与附件中的转让方证件类型一致",
    "auto_process_rules": "若无法成功提取对应字段中的任一数值或无法做出判断，则审核结果为待确认。若可正常提取对应全部字段值，且符合上述审核要求，则审核通过。若可正常提取对应全部字段值，但不符合上述审核要求，则审核不通过。"
}
```

**说明**：系统会自动从"转让方名称"提取规则中获取所有配置的参考材料（如《信息披露申请书》、《身份证》、《营业执照》），并自动获取用户表单填写的数据。

### 示例 2：字段审核 + 自定义映射

审核"是否有抵押"，需要理解整个文件内容：

```json
{
    "audit_type": "字段审核",
    "field_name": "是否有抵押",
    "mapping_type": "manual",
    "include_user_input": true,
    "audit_data_sources": [
        {
            "material_name": "《信息披露申请书》",
            "field_name": "是否有抵押",
            "description": "从申请书中提取是否有抵押字段"
        },
        {
            "material_name": "《关于抵押情况的说明文件》",
            "field_name": "全文",
            "description": "获取整个说明文件内容"
        }
    ],
    "audit_content": "1. 校验系统字段值是否与信息披露申请书字段值一致\n2. 理解《关于抵押情况的说明文件》的文件内容，判断所描述内容是否与系统字段值一致",
    "auto_process_rules": "若无法成功提取对应字段中的任一数值或无法做出判断，则审核结果为待确认。若可正常提取对应全部字段值，且符合上述审核要求，则审核通过。若可正常提取对应全部字段值，但不符合上述审核要求，则审核不通过。"
}
```

### 示例 3：文件审核

审核《信息披露申请书》封面是否加盖公章：

```json
{
    "audit_type": "文件审核",
    "field_name": "信息披露申请书",
    "audit_data_sources": [
        {
            "material_name": "《信息披露申请书》",

    "auto_process_rules": "若无法成功提取对应字段中的任一数值或无法做出判断，则审核结果为待确认。若可正常提取对应全部字段值，且符合上述审核要求，则审核通过。若可正常提取对应全部字段值，但不符合上述审核要求，则审核不通过。"
}
```

## API 接口

### 创建审核规则

**POST** `/web/rule-configs/{config_id}/audit-rules/create`

**表单参数**：
- `audit_type`: 审核类型（字段审核/文件审核）
- `field_name`: 审核字段/文件名称
- `mapping_type`: 映射类型（auto/manual，字段审核时）
- `source_field_name`: 源字段名称（自动映射时）
- `include_user_input`: 是否包含用户表单数据（默认 true）
- `audit_data_sources_json`: 审核数据源 JSON 字符串（自定义映射或文件审核时）
- `audit_content`: 审核内容
- `auto_process_rules`: 自动处理规则
- `notes`: 备注

### 更新审核规则

**POST** `/web/rule-configs/{config_id}/audit-rules/{rule_id}/update`

参数同创建接口。

## 前端使用指南

### 字段审核 - 自动映射

1. 选择审核类型：字段审核
2. 选择映射类型：自动映射
3. 从下拉框选择源字段（提取规则）
4. 勾选"包含用户表单数据"（可选）
5. 填写审核内容和处理规则

### 字段审核 - 自定义映射

1. 选择审核类型：字段审核
2. 选择映射类型：自定义映射
3. 点击"添加数据源"按钮
4. 为每个数据源配置：
   - 选择材料名称
   - 填写字段名称（或"全文"）
   - 填写说明（可选）
5. 填写审核内容和处理规则

### 文件审核

1. 选择审核类型：文件审核
2. 点击"添加数据源"按钮
3. 配置审核数据源（同上）
4. 填写审核内容和处理规则

## 迁移指南

### 旧数据结构

```json
{
    "audit_materials": ["《信息披露申请书》", "《房屋所有权证》"],
    "audit_material_fields": [
        "《房屋所有权证》-房屋坐落",
        "《信息披露申请书》-坐落位置"
    ]
}
```

### 新数据结构

```json
{
    "audit_data_sources": [
        {
            "material_name": "《房屋所有权证》",
            "field_name": "房屋坐落"
        },
        {
            "material_name": "《信息披露申请书》",
            "field_name": "坐落位置"
        }
    ]
}
```

**迁移脚本**：如果需要，可以编写脚本将旧数据转换为新格式。

## 注意事项

1. **默认映射类型**：字段审核时默认为自动映射
2. **用户表单数据**：默认包含，系统会根据 `field_name` 自动匹配
3. **全文获取**：`field_name` 为空、"全文"或 null 时，表示获取整个材料内容
4. **文件审核**：不使用映射类型，直接配置数据源
5. **必填验证**：
   - 自动映射时，必须填写 `source_field_name`
   - 自定义映射或文件审核时，必须至少有一个 `audit_data_source`

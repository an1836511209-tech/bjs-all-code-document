# 审核接口优化方案（按规则维度组织）

## 改动概述

对 `/audit/sync` 接口进行了重构，核心改动：

1. **返回请求入参**：响应数据中完整返回 `confirmed_fields`
2. **按规则维度组织**：每个审核结果包含完整上下文（提取数据+审核结果）
3. **包含提取数据**：字段审核结果中嵌入提取任务的溯源信息
4. **文件审核增强**：文件审核类型包含审核要点、上传文件等信息
5. **人工审核标注**：自动标注需要人工审核的字段

---

## 核心设计：按规则维度组织数据

### 设计理念

**旧结构（平铺）**：审核结果与提取结果分离，前端需要额外关联
**新结构（嵌套）**：按审核规则组织，每个规则包含完整上下文

### 数据结构对比

## 详细改动

### 1. AuditResult 重构（核心变化）

#### 基础字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `audit_id` | string | 审核ID |
| `audit_rule_id` | string | 审核规则ID（来自配置）|
| `audit_rule_name` | string | 审核规则名称 |
| `audit_type` | enum | 审核类型：字段审核、文件审核、人工审核 |
| `audit_result` | enum | 审核结果：passed、failed、pending、manual_review |
| `audit_status` | enum | 审核状态：completed、processing、failed |
| `audit_explanation` | string | 审核说明 |
| `confidence` | float | 审核置信度 |

#### 字段审核专用结构

**核心变化**：`related_fields` 从简单的字段名数组变为包含完整提取数据的对象数组

**重要**：`extraction_data` 使用与 `/extraction/sync` 接口完全相同的数据结构（`FieldExtractionResult`），前端组件可直接复用。

```yaml

    field_value: "北京市朝阳区建国路1号"  # 用户确认的值

    extraction_data:  # ✅ 新增：提取任务的数据（结构与提取接口一致）
      field_id: "field_001"
      field_name: "坐落位置"
      field_type: "text"
      values:  # 与提取接口的 ExtractedFieldValue[] 结构完全一致
        - source_file_type: "info_disclosure_application"
          source_file_name: "信息披露申请书.pdf"
          source_field_name: "坐落位置"
          extracted_value: "北京市朝阳区建国路1号"
          extract_status: "success"
          confidence: 0.98
          sources:  # 溯源信息（SourceInfo 结构）
            - source_file_type: "info_disclosure_application"
              source_file_name: "信息披露申请书.pdf"
              source_field: "坐落位置"
              source_content: "坐落位置：北京市朝阳区建国路1号"
              preview_image_url: "https://minio.../highlights/location_001.png"
              page_number: 2
              coordinates: {x: 120, y: 300, width: 400, height: 30}

        - source_file_type: "property_certificate"
          source_file_name: "房屋所有权证.pdf"
          source_field_name: "房屋坐落"

          extract_status: "success"
          confidence: 0.96
          sources: [...]
      error_message: null
```

**数据结构一致性保证**：

| 字段路径 | 提取接口 | 审核接口 | 说明 |
|---------|---------|---------|------|
| `results[]` | `FieldExtractionResult[]` | `audit_results[].related_fields[].extraction_data` | 完全一致 |
| `.field_id` | ✓ | ✓ | 字段ID |
| `.field_name` | ✓ | ✓ | 字段名称 |
| `.field_type` | ✓ | ✓ | 字段类型 |
| `.values[]` | ✓ | ✓ | ExtractedFieldValue[] |
| `.values[].sources[]` | ✓ | ✓ | SourceInfo[] |
| `.error_message` | ✓ | ✓ | 错误信息 |

**前端组件复用**：
```typescript
// 提取接口渲染组件
<FieldExtractionView data={extractionResponse.data.results[0]} />

// 审核接口可以复用相同组件
<FieldExtractionView 
  data={auditResponse.data.audit_results[0].related_fields[0].extraction_data} 
/>
```

**数据来源说明**：
- `field_value`: 来自请求入参 `confirmed_fields`
- `extraction_data`: 来自提取任务的结果（可能来自缓存或实时提取），结构完全复用提取接口
- `sources`: 包含溯源坐标、预览图URL等信息

#### 文件审核专用字段

| 字段名 | 类型 | 说明 | 数据来源 |
|--------|------|------|----------|
| `file_type` | string | 文件类型 | 审核规则配置中的 `material_name` |
| `audit_points` | string | 审核要点 | 审核规则配置中的 `audit_content` |

**uploaded_files 数组结构：**

## 业务逻辑说明

### 整体处理流程

```
1. 接收审核请求（confirmed_fields + files）
2. 加载审核规则配置
3. 【提取阶段】检查缓存或执行字段提取（获取溯源数据）
4. 【审核阶段】遍历审核规则，调用LLM审核
5. 【合并阶段】将提取数据嵌入审核结果
6. 【补全阶段】标注需人工审核的字段
7. 返回完整结果
```

### 提取数据获取逻辑

**关键问题**：审核时如何获取提取任务的数据？

**解决方案**：利用缓存机制复用提取结果

```python
# 1. 计算附件哈希
files_hash = compute_files_hash(request.files, audit_type)

# 2. 查找缓存的提取任务
cached_extraction = task_store.find_task_by_files_hash(
    files_hash=files_hash,
    task_type=TaskType.EXTRACTION,
    only_completed=True
)

if cached_extraction:
    # 复用提取结果（包含溯源信息）
    extraction_results = cached_extraction.result["results"]
else:
    # 执行新的提取任务
    extraction_results = await extraction_service.extract_fields(...)
```

**缓存命中条件**：
- 相同的附件（通过哈希判断）
- 相同的业务类型（extraction_type）
- 提取任务已完成

### 字段审核数据组装

**目标**：将提取数据嵌入到审核结果的 `related_fields` 中

```python
def build_field_audit_result(audit_rule, confirmed_fields, extraction_results):
    """构建字段审核结果"""
    related_fields = []
    
    for field_name in audit_rule.related_fields:
        # 1. 从 confirmed_fields 获取用户确认的值
        confirmed_field = find_field(confirmed_fields, field_name)
        
        # 2. 从 extraction_results 获取提取数据（FieldExtractionResult）
        extraction_data = find_extraction_data(extraction_results, field_name)
        
        # 3. 组装完整的字段数据
        related_fields.append({
            "field_name": field_name,
            "field_value": confirmed_field.field_value,
            "field_type": confirmed_field.field_type,
            # ✅ 直接复用 FieldExtractionResult 结构
            "extraction_data": extraction_data.model_dump() if extraction_data else None
            # extraction_data 包含：
            # - field_id, field_name, field_type
            # - values: List[ExtractedFieldValue]  包含溯源信息
            # - error_message
        })
    
    return AuditResult(
        audit_type="字段审核",
        related_fields=related_fields,
        audit_result=llm_audit_result,
        ...
    )
```

### 文件审核处理流程

1. **规则配置匹配**
   - 从审核规则配置的 `audit_data_sources` 中获取 `material_name`
   - 将 `material_name` 作为 `file_type` 返回

2. **文件匹配逻辑**
   ```python
   def match_files_by_material_name(material_name, files):
       """根据 material_name 匹配已上传文件"""
       # 使用 LABEL_TO_FILE_TYPE 映射
       file_type = LABEL_TO_FILE_TYPE.get(material_name)
       
       if not file_type:
           return []
       
       # 在请求 files 中查找匹配的文件
       matched_files = [
           f for f in files 
           if f.file_type == file_type.value
       ]
       
       return matched_files
   ```

3. **审核要点和详情**
   - `audit_points`: 直接取规则配置中的 `audit_content`
   - `audit_details`: 从 LLM 审核响应中提取 `audit_analysis`

**示例映射**：
```
material_name: "《信息披露申请书》"
  ↓ LABEL_TO_FILE_TYPE 映射
file_type: FileType.INFO_DISCLOSURE_APPLICATION
  ↓ 在 request.files 中查找
matched_files: [
  {
    "file_name": "信息披露申请书.pdf",
    "file_url": "https://...",
    "file_type": "info_disclosure_application"
  }
]
```

### 人工审核标注逻辑

**触发条件**：`confirmed_fields` 中的字段未被任何审核规则覆盖

```python
def add_manual_review_items(confirmed_fields, audit_results, extraction_results):
    """添加需人工审核的字段"""
    # 1. 收集已审核的字段
    audited_fields = set()
    for result in audit_results:
        for field in result.related_fields:
            audited_fields.add(field.field_name)
    
    # 2. 找出未审核的字段
    for field in confirmed_fields:
        if field.field_name not in audited_fields:
            # 获取该字段的提取数据（FieldExtractionResult）
            extraction_data = find_extraction_data(extraction_results, field.field_name)
            
            # 创建人工审核项
            audit_results.append(AuditResult(
                audit_type="人工审核",
                audit_result="manual_review",
                audit_explanation="该字段未配置自动审核规则，需要人工审核",
                related_fields=[{
                    "field_name": field.field_name,
                    "field_value": field.field_value,
                    "field_type": field.field_type,
                    # ✅ 直接复用 FieldExtractionResult 结构
                    "extraction_data": extraction_data.model_dump() if extraction_data else None
                    # 即使是人工审核，也提供完整的提取数据和溯源信息
                    # 便于人工审核员查看原文档截图
                }]
            ))
```

**示例场景**：
```
confirmed_fields: ["坐落位置", "房屋面积", "产权人"]
agent审核的规则: 
  - 规则1: ["坐落位置", "房屋面积"]
  - 规则2: 文件审核（不关联字段）

结果: "产权人" 未被任何规则覆盖 → 标注为 manual_review
```

### 2. Service 层处理

在 `src/services/audit/service.py` 中：

1. **获取提取数据（关键步骤）**
   ```python
   async def audit_fields(request: AuditRequest, enable_cache: bool = True):
       # 1. 计算附件哈希
       files_hash = FileHasher.compute_files_hash(
           files=request.files,
           extraction_type=request.audit_type
       )
       
       # 2. 查找或执行提取任务
       extraction_results = None
       if enable_cache and files_hash:
           cached_task = await task_store.find_task_by_files_hash(
               files_hash=files_hash,
               task_type=TaskType.EXTRACTION,
               only_completed=True
           )
           if cached_task and cached_task.result:
               # 复用缓存的提取结果
               extraction_results = cached_task.result.get("results", [])
       
       if not extraction_results:
           # 执行新的提取任务
           extraction_response = await extraction_service.extract_fields(...)
           extraction_results = extraction_response.results
       
       # extraction_results 是 List[FieldExtractionResult]
   ```

2. **字段审核数据组装**
   ```python
   def build_field_audit_result(audit_rule, confirmed_fields, extraction_results):
       related_fields = []
       for field_name in audit_rule.related_fields:
           confirmed_field = find_confirmed_field(confirmed_fields, field_name)
           # ✅ 从提取结果中找到对应的 FieldExtractionResult
           extraction_data = find_extraction_result(extraction_results, field_name)
           
           related_fields.append(RelatedFieldInfo(
               field_name=field_name,
               field_value=confirmed_field.field_value,
               field_type=confirmed_field.field_type,
               # ✅ 直接复用，前端组件可直接渲染

           ))
       
       return AuditResult(
           audit_type="字段审核",
           related_fields=related_fields,
           ...
       )
   ```

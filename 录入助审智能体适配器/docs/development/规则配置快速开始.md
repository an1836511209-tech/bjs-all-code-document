## 📋 核心功能演示

### Web界面操作

#### 查看配置列表
访问: http://localhost:8580/web/rule-configs

你会看到：
- 大宗实物-房产交易规则配置（3个提取规则 + 2个审核规则）
- 小宗实物-动产交易规则配置（1个提取规则 + 1个审核规则）

#### 创建新配置
1. 点击"新建配置"按钮
2. 填写配置信息：
   - 配置名称：如"大宗实物-车辆交易规则"
   - 业务类型：选择"大宗实物"或"小宗实物"
   - 配置描述：简要说明用途
3. 点击"创建配置"

#### 查看配置详情
1. 在列表中点击某个配置的"查看"按钮
2. 可以看到：
   - 配置基本信息
   - 所有提取规则（可展开查看详情）
   - 所有审核规则（可展开查看详情）

#### 添加提取规则
1. 在配置详情页，点击"添加提取规则"
2. 在弹出的表单中填写：
   - **字段名称**: 如"房产面积"
   - **字段类型**: 选择"text"、"single_choice"或"multiple_choice"
   - **参考材料**: 用逗号分隔，如"《房屋所有权证》,《不动产权证书》"
   - **提取逻辑**: 用自然语言描述，如"从《房屋所有权证》中提取建筑面积字段"
   - **接口配置**（可选）:
     - 接口URL: 如"http://api.example.com/verify"
     - 请求方法: GET/POST
     - 超时时间: 默认30秒
   - **备注**: 如"必填字段"
3. 点击"添加"

#### 添加审核规则
1. 在配置详情页，点击"添加审核规则"
2. 在弹出的表单中填写：
   - **审核字段名称**: 如"房产面积"
   - **审核材料**: 用逗号分隔，如"《申请书》,《证书》"
   - **审核材料字段**: 每行一个，如：
     ```
     《房屋所有权证》-建筑面积
     《信息披露申请书》-房产面积
     ```
   - **审核内容**: 如"校验不同材料中面积数值是否一致"
   - **比对方式**: 如"字段值比对"
   - **自动处理规则**: 每行一条，如：
     ```
     若无法提取任一字段值，则审核结果为待确认
     若所有字段值一致，则审核通过
     若字段值不一致，则审核不通过
     ```
3. 点击"添加"

#### 删除规则
- 展开规则详情，点击"删除"按钮
- 确认删除操作

### API调用示例

#### 获取配置列表
```bash
curl http://localhost:8580/api/v1/rule-configs
```

响应示例：
```json
{
  "total": 2,
  "items": [
    {
      "id": "b1a7cd15-8a4f-4b64-a010-c657f23eb3f8",
      "name": "大宗实物-房产交易规则配置",
      "business_type": "大宗实物",
      "extraction_rules": [...],
      "audit_rules": [...]
    }
  ]
}
```

#### 获取配置详情
```bash
curl http://localhost:8580/api/v1/rule-configs/{config_id}
```

#### 创建配置
```bash
curl -X POST http://localhost:8580/api/v1/rule-configs \
  -H "Content-Type: application/json" \
  -d '{
    "name": "大宗实物-车辆交易规则",
    "business_type": "大宗实物",
    "description": "车辆交易相关规则"
  }'
```

```

├── b1a7cd15-8a4f-4b64-a010-c657f23eb3f8.json  # 大宗实物配置
```

## 💡 最佳实践

### 提取规则设计
1. **字段名称**: 使用业务系统中的标准名称
2. **提取逻辑**: 清晰描述从哪个材料的哪个位置提取什么内容
3. **参考材料**: 使用书名号《》包裹材料名称
4. **接口配置**: 仅在需要外部数据辅助时配置

### 审核规则设计
1. **审核材料**: 列出所有需要的材料
2. **材料字段**: 明确每个材料中对应的字段名
3. **审核内容**: 详细描述审核的具体要求
4. **处理规则**: 覆盖所有可能的情况（待确认/通过/不通过）

### 命名规范
- **配置名称**: `业务类型-具体场景`，如"大宗实物-房产交易规则"
- **字段名称**: 使用中文，与业务系统保持一致
- **材料名称**: 使用书名号《》，如"《信息披露申请书》"

## 🔧 故障排查

### 问题: 服务启动失败
**解决**: 检查端口8580是否被占用
```bash
netstat -ano | findstr :8580
```

### 问题: 无法访问Web界面
**解决**: 
1. 确认服务已启动
2. 测试健康检查: http://localhost:8580/health
3. 查看启动日志

### 问题: 规则保存失败
**解决**:
1. 检查 `data/rule_configs/` 目录是否存在
2. 检查目录写入权限
3. 查看日志文件了解具体错误

# 规则配置编辑和搜索功能说明

## 概述

本次更新为规则配置管理系统添加了两个重要功能：
1. **规则编辑功能** - 支持修改已添加的提取规则和审核规则
2. **快速搜索功能** - 支持在配置列表和规则详情页中快速检索

## 新增功能详情

### 1. 规则编辑功能

#### 1.1 功能描述
- 用户可以编辑已创建的提取规则和审核规则
- 编辑时会自动填充原有数据
- 支持修改规则的所有字段
- 编辑操作复用添加规则的模态框，减少代码冗余

#### 1.2 使用方式
1. 在规则配置详情页，展开任意提取规则或审核规则
2. 点击规则底部的 **"编辑"** 按钮（蓝色按钮）
3. 在弹出的模态框中修改规则内容
4. 点击 **"更新"** 按钮（黄色按钮）保存修改
5. 页面会自动刷新并显示更新后的规则

#### 1.3 技术实现
- **后端 API 端点**：
  - `POST /web/rule-configs/{config_id}/extraction-rules/{rule_id}/update` - 更新提取规则
  - `POST /web/rule-configs/{config_id}/audit-rules/{rule_id}/update` - 更新审核规则
  
- **前端实现**：
  - 规则数据存储在 HTML 元素的 `data-rule-data` 属性中
  - JavaScript 函数动态修改模态框标题、按钮和表单action
  - 自动填充表单字段，包括多选下拉框
  - 模态框关闭时自动重置为添加模式

### 2. 快速搜索功能

#### 2.1 配置列表页搜索

**功能描述**：
- 在配置列表页顶部提供搜索框
- 支持按配置名称、业务类型、描述进行实时搜索
- 搜索结果即时显示，无需点击搜索按钮
- 无匹配结果时显示提示信息

**使用位置**：
- 访问 `http://localhost:8580/web/rule-configs`
- 在页面顶部的搜索框中输入关键词

**搜索范围**：
- 配置名称
- 业务类型（如：不动产抵押登记）
- 配置描述

#### 2.2 规则详情页筛选

**功能描述**：
- 在提取规则和审核规则部分分别提供搜索框
- 支持按字段名称、参考材料、提取逻辑、审核内容等进行筛选
- 筛选结果即时显示，隐藏不匹配的规则

**使用位置**：
- 访问任意配置的详情页
- 在"提取规则"部分和"审核规则"部分顶部的搜索框中输入关键词

**搜索范围**：
- **提取规则**：字段名称、字段类型、参考材料、提取逻辑、选项列表、API配置、备注等
- **审核规则**：审核类型、字段名称、审核材料、审核内容、比对方式、自动处理规则、备注等

#### 2.3 搜索特点
- **实时搜索**：输入即搜索，无需按回车或点击按钮
- **模糊匹配**：支持部分关键词匹配
- **大小写不敏感**：搜索时忽略大小写
- **全文搜索**：搜索规则的所有可见内容

## 使用示例

### 示例 1：编辑提取规则

```
1. 访问配置详情页
2. 展开需要修改的提取规则
3. 点击"编辑"按钮
4. 修改字段内容（例如：更新提取逻辑描述）
5. 点击"更新"按钮
6. 系统自动保存并刷新页面
```

### 示例 2：搜索配置

```
1. 访问配置列表页 (http://localhost:8580/web/rule-configs)
2. 在搜索框中输入"抵押"
3. 系统即时显示所有包含"抵押"关键词的配置
4. 清空搜索框，所有配置重新显示
```

### 示例 3：筛选规则

```
1. 访问配置详情页
2. 在提取规则搜索框中输入"坐落"
3. 系统即时筛选出所有与"坐落"相关的提取规则
4. 在审核规则搜索框中输入"一致性"
5. 系统即时筛选出所有与"一致性"相关的审核规则
```

## 技术架构

### 后端更新

**文件**：`src/api/v1/endpoints/rule_config_web.py`

新增端点：
```python
# 更新提取规则
@router.post("/{config_id}/extraction-rules/{rule_id}/update")
async def update_extraction_rule(...)

# 更新审核规则
@router.post("/{config_id}/audit-rules/{rule_id}/update")
async def update_audit_rule(...)
```

### 前端更新

**文件**：`src/templates/rule_config/detail.html`、`src/templates/rule_config/list.html`

新增功能：
1. 规则数据存储在 `data-rule-data` 属性中
2. JavaScript 编辑函数：`editExtractionRule()` 和 `editAuditRule()`
3. JavaScript 重置函数：`resetExtractionRuleModal()` 和 `resetAuditRuleModal()`
4. 实时搜索事件监听器

## 注意事项

1. **编辑操作不可撤销**：编辑并保存后会立即覆盖原有数据
2. **搜索只在前端进行**：所有数据已加载到页面，搜索不会向服务器发送请求
3. **模态框复用**：编辑功能复用添加模态框，关闭后会自动重置
4. **数据验证**：表单提交时会进行客户端和服务器端双重验证

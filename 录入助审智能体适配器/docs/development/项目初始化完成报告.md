### 核心功能模块

1. **文件质量检测模块**
   - 清晰度检测（IQA-PyTorch / ImgDetect）
   - 分辨率检测
   - 遮挡检测
   - 支持PDF、图片等多种格式

2. **智能字段提取模块**
   - 基于LLM的语义理解
   - PDF/Word文档解析
   - 多文件联合提取
   - 溯源信息记录
   - 同步/流式（SSE）两种模式

3. **规则自动审核模块**
   - 字段值比对
   - 内容审核
   - 交叉验证
   - 自定义规则引擎
   - 审核结果溯源

4. **规则配置管理模块**
   - 提取规则配置
   - 审核规则配置
   - 规则版本管理
   - CRUD接口

## 🔧 开发流程

### 功能开发流程

```bash
# 1. 创建功能分支
git checkout develop
git pull origin develop
git checkout -b feature/功能名称

# 2. 编写代码
# 遵循代码规范，编写测试

# 3. 代码检查
poetry run black src/ tests/
poetry run isort src/ tests/
poetry run flake8 src/ tests/
poetry run pytest

# 4. 提交代码
git add .
git commit -m "feat(模块): 功能描述"
git push origin feature/功能名称

# 5. 合并到develop
git checkout develop
git merge --no-ff feature/功能名称
git push origin develop
```

### 提交规范

```
<type>(<scope>): <subject>

type:
  - feat: 新功能
  - fix: 修复bug
  - docs: 文档更新
  - style: 代码格式
  - refactor: 重构
  - perf: 性能优化
  - test: 测试相关
  - chore: 构建/工具

scope: 影响范围（extraction, audit, quality等）
subject: 简短描述
```

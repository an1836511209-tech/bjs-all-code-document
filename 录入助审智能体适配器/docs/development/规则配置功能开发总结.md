## 功能概述

本次开发实现了一套完整的规则配置管理系统，用于北交所录入助审系统的提取规则和审核规则配置。

### 核心特性

1. **业务类型支持**
   - 大宗实物
   - 小宗实物

2. **提取规则管理**
   - 字段名称定义
   - 字段类型：文本、单选、多选
   - 参考材料配置
   - 提取逻辑（自然语言描述）
   - 外部接口配置（可选）
   - 选项列表配置

3. **审核规则管理**
   - 审核字段定义
   - 审核材料列表
   - 审核材料字段映射
   - 审核内容描述
   - 比对方式配置
   - 自动处理规则

4. **管理界面**
   - 配置列表页面
   - 配置创建页面
   - 配置详情页面（含规则管理）
   - 响应式设计（Bootstrap 5）
   - 友好的用户体验

5. **RESTful API**
   - 完整的CRUD接口
   - 规则配置管理
   - 提取规则管理
   - 审核规则管理
   - OpenAPI文档

## 技术架构

### 规则配置语法

采用 **JSON格式** 作为规则配置的存储格式，优点：
- ✅ 易于读写和解析
- ✅ 结构清晰，易于理解
- ✅ Python原生支持
- ✅ 可以轻松存储到数据库
- ✅ 支持版本控制

### 数据模型层 (Pydantic)

**文件**: `src/schemas/rule_config.py`

定义的主要模型：
- `RuleConfig`: 规则配置集合
- `ExtractionRule`: 提取规则
- `AuditRule`: 审核规则
- `ApiConfig`: 接口配置
- 各种枚举类型（业务类型、字段类型、HTTP方法等）
- API请求/响应模型

### 业务逻辑层 (Service)

**文件**: `src/services/rule_config_service.py`

核心类：`RuleConfigService`

功能：
- 规则配置的增删改查
- 提取规则的增删改查
- 审核规则的增删改查
- JSON文件存储管理
- 单例模式实现

### API层

**文件**: 
- `src/api/v1/endpoints/rule_config.py`: RESTful API端点
- `src/api/v1/endpoints/rule_config_web.py`: Web界面路由

提供的接口：
- `POST /api/v1/rule-configs`: 创建配置
- `GET /api/v1/rule-configs`: 获取配置列表
- `GET /api/v1/rule-configs/{id}`: 获取配置详情
- `PUT /api/v1/rule-configs/{id}`: 更新配置
- `DELETE /api/v1/rule-configs/{id}`: 删除配置
- 提取规则和审核规则的完整CRUD接口

### 前端层 (Jinja2 + Bootstrap5)

**文件**: `src/templates/rule_config/`
- `base.html`: 基础模板
- `list.html`: 配置列表页
- `create.html`: 创建配置页
- `detail.html`: 配置详情页

特点：
- 使用Bootstrap 5实现响应式设计
- 使用Bootstrap Icons图标库
- 模态框实现规则的添加
- 手风琴展示规则详情
- 友好的操作提示和确认

### 数据存储

**目录**: `data/rule_configs/`

存储方式：
- 每个配置一个JSON文件
- 文件名为配置ID
- 包含完整的配置信息（含所有规则）

## 接口配置功能

### 接口配置字段

在提取规则中可以配置外部接口：

```json
{
  "api_config": {
    "url": "http://api.example.com/dict",
    "method": "GET",
    "params": {},
    "headers": {},
    "timeout": 30,
    "description": "获取字典值"
  }
}
```

### 使用场景

接口配置主要用于：
1. 获取字典值供LLM参考
2. 验证提取的字段值
3. 获取外部系统的数据
4. 实时数据查询

## 规则配置示例

### 提取规则示例

```json
{
  "field_name": "坐落位置",
  "field_type": "text",
  "reference_materials": ["《信息披露申请书》"],
  "extraction_logic": "从《信息披露申请书》中提取'坐落位置'字段的值",
  "api_config": null,
  "enabled": true,
  "notes": "必填字段"
}
```

### 审核规则示例

```json
{
  "field_name": "坐落位置",
  "audit_materials": ["《信息披露申请书》", "《房屋所有权证》"],
  "audit_material_fields": [
    "《房屋所有权证》-房屋坐落",
    "《信息披露申请书》-坐落位置"
  ],
  "audit_content": "校验系统字段值是否与审核材料字段内容一致",
  "comparison_method": "字段值比对",
  "auto_process_rules": [
    "若无法成功提取对应字段中的任一数值或无法做出判断，则审核结果为待确认",
    "若可正常提取对应全部字段值，且符合上述审核要求，则审核通过",
    "若可正常提取对应全部字段值，但不符合上述审核要求，则审核不通过"
  ],
  "enabled": true
}
```

# 省市区字段级联提取功能文档

## 功能概述

实现了省市区字段的级联提取功能，通过动态注入上一级的可选值到 extraction_logic 中，提高模型提取的准确率。

## 实现时间

2025-12-04

## 功能特性

### 1. 自动识别区域字段

系统会自动识别以下两组区域字段：

**组1 - 标的所在地：**
- `BDSZDS` (省份)
- `BDSZDSHI` (城市)
- `BDSZDQX` (区县)

**组2 - 转让方住所：**
- `PROVINCE` (省份)
- `CITY` (城市)
- `QX` (区县)

### 2. 级联提取策略

- **两组之间**：并行处理（互不依赖，可同时进行）
- **组内字段**：串行提取（省 → 市 → 区，逐级依赖）
- **普通字段**：在区域字段处理完成后，按原有批量逻辑处理

### 3. 动态枚举值注入

每个层级提取时，会根据上一级的结果动态注入可选值：

#### 省份提取
```
原始 extraction_logic:
字段名：BDSZDS；备注：标的所在地(省)，注意只提取省份信息

增强后 extraction_logic:
字段名：BDSZDS；备注：标的所在地(省)，注意只提取省份信息

【可选省份】：北京市, 天津市, 河北省, 山西省, ... (全部36个)
```

#### 城市提取（假设省份提取到"北京市"）
```
原始 extraction_logic:
字段名：BDSZDSHI；备注：标的所在地(市)，只提取市信息

增强后 extraction_logic:
字段名：BDSZDSHI；备注：标的所在地(市)，只提取市信息

【北京市 的可选城市】：市辖区, 县
```

#### 区县提取（假设城市提取到"市辖区"）
```
原始 extraction_logic:
字段名称：BDSZDQX；备注：标的所在地(区县)，只提取区县信息

增强后 extraction_logic:
字段名称：BDSZDQX；备注：标的所在地(区县)，只提取区县信息

【市辖区 的可选区县】：东城区, 西城区, 朝阳区, ... (全部16个)
```

## 技术实现

### 核心文件

1. **`src/utils/region_data_helper.py`** (新建)
   - 省市区数据助手类
   - 加载并管理 `data/region_data.json` 数据
   - 提供查询接口：`get_all_provinces()`, `get_cities_by_province()`, `get_districts_by_city()`
   - 支持名称模糊匹配（如"北京"/"北京市"）
   - 单例模式，避免重复加载

2. **`src/services/extraction/service.py`** (修改)
   - 新增 `_identify_region_field_groups()` - 识别并分组区域字段
   - 新增 `_extract_region_fields_cascade()` - 级联提取区域字段
   - 修改 `_extract_all_fields()` - 集成区域字段优先处理逻辑

### 数据来源

使用 `data/region_data.json` 文件，包含：
- 36个省级行政区
- 所有城市（按省分组）
- 所有区县（按市分组）

数据格式：
```json
{
  "provinces": [
    {
      "name": "北京市",
      "id": 110000,
      "cities": [
        {
          "name": "市辖区",
          "id": 110100,
          "districts": [
            {"name": "东城区", "id": 110101},
            ...
          ]
        }
      ]
    }
  ]
}
```

## 工作流程

```
┌─────────────────────────────────────────┐
│ 1. 识别区域字段和普通字段                │
│    - 区域字段：分为2组，每组3个字段       │
│    - 普通字段：其他所有字段               │
└────────────┬────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│ 2. 预生成 Anchor Markdown 缓存           │
│    - 为每个文件类型生成一次               │
│    - 后续字段复用，避免重复转换           │
└────────────┬────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│ 3. 阶段0：优先处理区域字段（级联提取）   │
│    ┌──────────────┬──────────────┐      │
│    │  组1并行     │  组2并行     │      │
│    │  ↓           │  ↓           │      │
│    │ 省→市→区     │ 省→市→区     │      │
│    │ (串行)       │ (串行)       │      │
│    └──────────────┴──────────────┘      │
└────────────┬────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│ 4. 阶段1：处理普通字段（批量模式）       │
│    - 按参考材料分组                      │
│    - 批量提取 + 溯源                     │
└────────────┬────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│ 5. 合并结果并按原始顺序排列               │
│    - 区域字段结果 + 普通字段结果         │
│    - 保持字段原始顺序                    │
└────────────┬────────────────────────────┘
             │
             ▼
┌─────────────────────────────────────────┐
│ 6. 阶段2：批量生成高亮图                 │
│    - 所有字段统一生成高亮                │
└─────────────────────────────────────────┘
```

## 使用方式

### 自动启用

系统会自动检测字段名，无需额外配置。只要规则配置中包含以下字段名之一，就会自动启用级联提取：

- 标的所在地组：`BDSZDS`, `BDSZDSHI`, `BDSZDQX`
- 转让方住所组：`PROVINCE`, `CITY`, `QX`

## 性能影响

### 优势

1. **提高准确率**：通过注入标准行政区划数据，减少模型幻觉
2. **保持并发**：两组区域字段并行处理，不影响整体性能
3. **复用缓存**：Anchor Markdown 只生成一次，多字段复用

### 开销

1. **额外串行**：每组内部需要串行提取（省→市→区），但由于只有3个字段，影响较小
2. **Prompt 增长**：注入枚举值会增加 Prompt 长度（省份约 200 字符，城市/区县更少）

## 错误处理

### 提取失败情况

如果某一级提取失败或返回空值：
1. 记录警告日志
2. 下一级不注入枚举值（回退到原始 extraction_logic）
3. 继续提取，不阻塞流程

### 数据缺失情况

如果省市区数据文件不存在或损坏：
1. RegionDataHelper 会记录错误日志
2. 回退到原始提取逻辑（不注入枚举值）
3. 不影响其他字段的提取

## 后续优化建议

1. **智能纠错**：如果 LLM 返回"北京"，自动映射为"北京市"
2. **支持多值**：处理材料中出现多个不一致省份的情况
3. **缓存优化**：避免同一任务多次查询相同省市区数据
4. **按需加载**：RegionDataHelper 按需加载城市/区县数据，而非一次性加载全部

## 维护说明

### 更新区域数据

如果行政区划发生变化，更新数据：

1. 运行抓取脚本更新数据：
```bash
python scripts/fetch_region_data.py
```

2. 数据会保存到 `data/region_data.json`

3. 无需重启服务，RegionDataHelper 会在下次加载时自动使用新数据

### 添加新的区域字段组

如果需要添加新的区域字段组（如"受让方住所"），修改 `_identify_region_field_groups()` 方法：

```python
REGION_GROUPS_DEF = [
    ['BDSZDS', 'BDSZDSHI', 'BDSZDQX'],      # 标的所在地
    ['PROVINCE', 'CITY', 'QX'],             # 转让方住所
    ['SR_PROVINCE', 'SR_CITY', 'SR_QX']     # 受让方住所（新增）
]
```

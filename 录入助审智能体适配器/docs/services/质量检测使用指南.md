# 图像质量检测使用指南

## 📖 概述

图像质量检测模块用于自动评估上传文档的质量,包括清晰度、分辨率和遮挡检测。**已针对黑白PDF扫描件进行优化**。

## 🚀 快速开始

### 基本使用

```python
from src.services.quality.quality_checker import QualityChecker
from PIL import Image

# 读取图像
image = Image.open('document.pdf')  # 或 .png, .jpg

# 执行质量检测
result = QualityChecker.check_image_quality(
    image=image,
    trace_id="your_trace_id"  # 可选,用于日志追踪
)

# 检查结果
print(f"综合状态: {result['overall_status']}")  # passed/warning/failed
print(f"消息: {result['message']}")
```

### 判断是否通过

```python
if result['overall_status'] == 'passed':
    # 质量检查通过
    process_document(image)
    
elif result['overall_status'] == 'warning':
    # 有轻微问题,建议检查但可以继续
    show_warning(result['message'])
    process_document(image)
    
else:  # failed
    # 质量问题严重,建议重新上传
    return {"error": result['message']}
```

## 🔧 配置说明

配置文件位于: `config/quality_config.py`

### 清晰度阈值

```python
CLARITY_THRESHOLDS = {
    'excellent': 70.0,  # 融合分数>=70: 优秀
    'good': 40.0,       # 融合分数>=40: 良好(通过)
    'fair': 20.0,       # 融合分数>=20: 一般(警告)
    'poor': 0.0         # 融合分数<20: 较差(失败)
}
```

**调整建议**:
- 如果误报率高(正常文档被判warning/failed): 降低`good`阈值,如35.0
- 如果漏报率高(模糊文档被判passed): 提高`good`阈值,如45.0

### 分辨率阈值

```python
RESOLUTION_THRESHOLDS = {
    'min_width': 600,           # 最低宽度
    'min_height': 800,          # 最低高度
    'recommended_width': 1200,  # 推荐宽度
    'recommended_height': 1600  # 推荐高度
}
```

**说明**:
- 600x800约为A4纸150 DPI扫描,满足基本OCR需求
- 1200x1600约为A4纸300 DPI扫描,获得更好识别效果

### 遮挡检测阈值

```python
OCCLUSION_THRESHOLDS = {
    # 通用阈值(彩色图/灰度图)
    'black_pixel_threshold': 30,     # 黑色像素阈值
    'max_noise_ratio': 0.10,         # 最大噪点占比10%
    'warning_noise_ratio': 0.08,     # 噪点警告阈值8%
    'max_black_ratio': 0.20,         # 最大黑色区域20%
    'warning_black_ratio': 0.15,     # 黑色区域警告15%
    
    # 黑白扫描件专用阈值(宽松策略)
    'extreme_black_threshold': 10,   # 极黑区域阈值
    'scan_max_black_ratio': 0.30,    # 允许30%极黑
    'scan_warning_black_ratio': 0.20, # 20%以上警告
}
```

**黑白扫描件处理逻辑**:
1. 自动识别为黑白扫描件
2. 使用极黑阈值(10)代替普通黑色阈值(30)
3. 跳过噪点检测(避免文字误判)
4. 使用宽松的失败阈值(30%)

        }

## ⚠️ 注意事项

### 1. 作为辅助工具而非绝对判断

- ✅ 提供质量评估参考
- ✅ 帮助用户发现潜在问题
- ❌ 不应作为强制卡控(硬性阻止)
- ❌ 算法不可能100%准确

### 2. 保留人工复核机制

## 🆘 常见问题

### Q1: 为什么清晰的文档被判为warning?

**原因**: 阈值可能设置过严
**解决**: 降低`CLARITY_THRESHOLDS['good']`,从40.0调整到35.0

### Q2: 为什么文字密集的扫描件被判为failed?

**原因**: 未正确识别为黑白扫描件
**解决**: 检查图像灰度分布,确认是否符合识别条件(黑白像素占比>85%)

### Q3: 如何调整检测严格程度?

**宽松策略**(减少误报):
```python
CLARITY_THRESHOLDS['good'] = 35.0  # 降低5
OCCLUSION_THRESHOLDS['scan_max_black_ratio'] = 0.35  # 提高到35%
```

**严格策略**(提高质量要求):
```python
CLARITY_THRESHOLDS['good'] = 45.0  # 提高5
OCCLUSION_THRESHOLDS['scan_max_black_ratio'] = 0.25  # 降低到25%
```

### Q4: 如何验证改进效果?

1. 收集50份你认为"正常"的黑白扫描文档
2. 运行批量测试
3. 统计有多少被判为`failed`
4. 目标: 误报率<5%

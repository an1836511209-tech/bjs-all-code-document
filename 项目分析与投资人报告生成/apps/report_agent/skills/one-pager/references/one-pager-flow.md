# 一页纸 BP — 流程细则

## 业务类型判定（`detect_one_pager_business_type`）

**材料路径**：可传 `/workspace/input` 原文件、`material_id`，或 UTF-8 文本。二进制输入会自动匹配 `/workspace/working/materials/{material_id}.json` 的解析正文。

**优先级**：材料原文关键词 > 文件名 > 用户显式输入。

| 关键词类别 | 命中词 |
|---|---|
| 产权 | 股权转让 / 产权转让 / 转让底价 / 受让方 / 受让条件 / 转让方 / 股权比例 / 挂牌转让 |
| 增资 | 增资 / 增资扩股 / 拟募集金额 / 募集资金 / 认购 / 新增注册资本 / 投资方 / 增资款 |

- 产权命中数 − 增资命中数  ≥ 2 → 直接判定
- 差 = 0 或 1 → 文件名命中其一则取文件名；否则 `status="needs_user_input"`
- 材料与文件名冲突 → 以材料为准，`conflict=true`

## 分段撰写：三段式（不是逐段递进）

**关键区别**：低代码工作流是**分板块级**——一次锁定 6 个标题，介绍写完后才写亮点且能看到介绍全文。我们早期版本是"逐段递进"（段 N 看段 1..N-1），会导致标题之间可能交叉、层级错位。

```
5.1 大纲       → 一次出 6 个标题 + 每段「内容要点 / 依据原文」
                 → check_one_pager_outline 强制决策表 + 唯一性 + 不交叉
5.2 介绍正文   → 只写 3 段（建议每段 225-250 字），写到亮点之前就停
5.3 亮点正文   → 读 5.2 全文后再写 3 段（建议每段 170-185 字）+ 投资人表
5.4 三道审查
```

## 连贯性策略

目标字数仅作建议，不为差几字或材料偏少反复改稿。渲染只拦截空段、结构错误及
介绍超过400 / 亮点超过220字的明显溢出；来源标记不计入字数，也不写入 Word 正文。

### 术语与人称

- 公司简称/全称全文统一，首次出现用全称，其后用简称
- 统一第三人称「公司」，禁「我们」「本项目」
- 赛道用词、产品名、体系代号（如 `1+3+N`、`Type-C`）保留原格式

### 反重复

- **分工边界**是主防线：介绍写「是什么」，亮点写「为什么值得投」
- 同一数字只在其归属板块出现一次
- 亮点段可用「前述」「上一段」回指，不复述细节

### 正反例

- ✅ 介绍：「公司以电子光学技术为核心，产品覆盖扫描电镜、FIB-SEM、CD-SEM」（构成）
- ✅ 亮点：「半导体设备国产化率不足 5%，该品类进口依赖度高，公司整建制团队构成稀缺供给」（论证）
- ❌ 三段介绍都写「公司以电子光学技术为核心」→ `section_restatement` 判 block

## 写作硬约束

| 约束 | 内容 |
|---|---|
| 句子级证据 | 每句必须能指出文档的具体依据；指不出来的删掉 |
| 禁止归因 | 材料未说明因果时禁止「源于/得益于/反映出/受益于/正是由于/归功于」 |
| 数字处理 | 直接引用原值，不精确推算，保留「多」「约」等模糊词；单位不一致需换算为统一单位 |
| 财务表述 | 项目介绍里的财务只呈现最新一期数值，不做跨年度对比、不用「显著提升」「大幅增长」 |
| 归因约束 | 未说明原因的变化不得推测；下滑/波动如实表述幅度，不得用「略有波动」淡化 |
| 粒度 | 禁商业配套品牌名、单项设施占地面积、工商登记信息、设备型号门禁品牌 |
| 语言 | 客观陈述不堆砌形容词；避免「公司致力于」「公司秉承」 |

## 投资人清单渲染

- 默认内部 20 + 网络 10
- 表格追加在正文末尾，仿宋_GB2312 / 8pt
- 列宽（pt）：序号 32 / 来源 46 / 类型 56 / 投资人名称 180 / 匹配理由 281
- 来源列渲染：内部库 / 网络
- 空清单：保留一行「暂无可用匹配数据」（不阻断）

## 渲染后校验

- `valid=True` 才推进发布
- `PAGE_LIMIT_EXCEEDED` 是不阻塞 warn
- `pages` 由 LibreOffice → PDF → pymupdf 数页；LibreOffice 缺失则降级为仅 XML 校验，`pages=None`

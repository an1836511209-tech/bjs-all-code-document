# 一页纸写作范式（来自已交付的优秀样本）

这份文件是从北交汇投实际交付的《优质项目集锦》里提炼出来的写法。它不规定
写什么内容（内容由材料决定），只规定**怎么写**。写正文前先读一遍。

---

## 一、基本结构：分点 + 小标题 + 论据

正文框只有一个段落，所以**必须用换行分点**，否则所有内容会连成一整段，
读者看不出分了几个点。

格式（每个正文框 2-3 点，每点一行）：

```
1.小标题。具体的论据，用事实和数字说话；
2.小标题。具体的论据；
3.小标题。具体的论据。
```

真实样本（细胞治疗项目）：

```
以 "GMP+GLP+GCP" 全流程规范为核心，覆盖细胞治疗全链条：
1.脐带采集。脐带组织来源于健康新生儿，需经伦理审查与知情同意，采集、运输、保存严格按照 SOP 执行；
2.干细胞制备与扩增。在 GMP 级车间完成间充质干细胞的分离和扩增，保障生产过程质量可控；
3.细胞检定。细胞工作库需在 GLP 级实验室完成生物学效力及安全性检定，通过严格质量控制体系保障产品质量；
4.临床应用。在国家卫健委和药监局监管下开展细胞收费治疗，同一间充质干细胞产品可用于多项疾病，应用广泛。
```

要点：

- **每条一行**，用 `1.` `2.` `3.` 编号，编号后紧跟小标题，小标题后加句号，再接内容
- 段首可以有一句总起（如上面的"以 GMP+GLP+GCP 全流程规范为核心…"）
- 每条之间用分号或句号收尾
- 小标题 4-8 字，是一个**判断**；后面紧跟着支撑它的事实

另一组样本的小标题：`研发团队优秀` `商业化进展明确` `战略规划清晰`
`填补技术空白` `研发团队强劲` `国产替代加速`。

**禁止**：把所有内容写成一段没有编号、没有小标题的连续叙述。

---

## 二、每一句都要有一个具体实体或数字

这是样本和我们草稿最大的差距。

| 我们的写法（概括） | 样本的写法（具体） |
|---|---|
| 客户覆盖国内主要前道设备厂商 | 已获得国网 5G 电力巡检订单，并与顺丰达成 300-500 架的采购意向 |
| 团队来自国际与本土龙头企业 | 核心团队由原陕飞集团总生产长领衔，绑定西北工业大学、南京航空航天大学共建博士工作站 |
| 产品性能达到行业领先水平 | "天目"是中国首款实现车规级集成电机驱动 SOC 芯片的国产替代产品 |
| 拥有多项专利 | 拥有发明专利 14 项、实用新型 22 项 |

**自检方法**：把每句话单独拿出来问一句 —— "这句话里有没有一个可以查证的名字、
型号、数字或机构？" 没有的话，要么补上具体事实，要么删掉。

允许的具体项：人名/职务、机构名、客户名、产品型号、订单数量、金额、比例、
专利数、认证名称、年份、参与机构。

---

## 三、不要用评价句填空

材料没给的信息，写「材料未披露」，**不要**用下面这类句子凑满一段：

- 在供应链中占据有利地位
- 业务扩张能力突出，市场需求旺盛
- 有助于快速推进产品验证与量产导入，降低产业化风险
- 专利布局覆盖核心零部件的设计、材料与制造工艺，构成技术竞争壁垒

这些句子**看起来像结论，实际上没有信息**。审阅者会立刻怀疑整篇的可信度。

样本里的评价句**永远紧跟在一个事实后面**，且那一句事实就支撑它：

> 核心团队由原陕飞集团总生产长等专家领衔（事实）→ 确保了深厚的工程管理与质量
> 控制底蕴（评价）

评价可以写，但前面必须有那个事实。事实没有，就不写评价。

---

## 四、不要开场白

样本没有"公司专注于……"这种自我介绍式的开头，直接进事实：

- ✗ `公司专注于半导体前道设备的精密零部件制造，主要面向集成电路制造关键环节提供核心部件。`
- ✓ `智芯半导体自主研发的"天目"汽车电机控制集成 SOC 芯片，是中国首款……`

如果第一句只是把公司名重复一遍，删掉它。

---

## 五、页面固定要素

每一页样本都有：

- **标题**：`<公司全称><增资/转让>项目`
- **页脚字段**：所属区域 / 所属赛道 / 对应持股比例 / 公司名称
- **免责声明**：整段固定文本，说明信息保密、不作保证
- **应用场景图**：竖排标签 + 一张产品/场景图

> 免责声明和固定字段由渲染层负责，模型不用写；但**写作时要意识到这是给外部
> 投资人看的正式材料**，不是内部笔记。

---

## 六、落笔前的四问

1. 每段有没有一个小标题？
2. 每句话里有没有可查证的实体或数字？
3. 有没有哪句只有评价、没有事实？——有就删。
4. 有没有把材料里给的具体名称写成了"主要厂商""多家客户"？——有就改回来。

四问全过再进入审查阶段。

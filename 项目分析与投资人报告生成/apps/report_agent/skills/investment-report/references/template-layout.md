参考文件：`resources/reference_data/report_agent/投资匹配报告模板参考/投资匹配报告模板.docx`

审计基线：SHA-256 `41921739E3DA627C90102B724923E1B8119B1874B8DC85B5467F62AEF3434951`；A4 纵向；左右边距 1.25 英寸，上下边距 1.00 英寸；标题使用方正小标宋简体约 22 pt 居中；一级标题使用黑体约 16 pt；二级标题使用楷体 GB2312 约 16 pt；正文使用仿宋 GB2312 约 16 pt、两端对齐。参考文件包含财务五列表格和投资人三列表格。

实现时应建立语义化样式和稳定的标题层级，而不是复制参考文件中的直接格式或编号错误。若目标环境缺少上述字体，应使用配置的兼容字体并在验证结果中披露。参考模板的任何示例事实和占位内容均不得进入报告。

已在项目 Docker runtime 使用 LibreOffice 7.4.7.2 渲染并检查参考文件全部 10 页。参考文件无页眉页脚、目录字段和 Heading 样式，59 个段落使用直接格式；财务表在第 2–3 页间断开，投资人表在第 8–10 页连续跨页。生产实现保留 A4、页边距、黑色中文标题层级和两类表格的视觉意图，但使用语义 Heading、重复表头、动态列宽和页码重建，不继承直接格式、错误编号或示例事实。

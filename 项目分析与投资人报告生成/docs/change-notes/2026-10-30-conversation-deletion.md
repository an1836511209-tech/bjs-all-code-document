# 会话删除与标题超时确认

控制台侧栏每条会话增加垃圾桶按钮。删除前确认，已提交到后端的会话调用 `DELETE /api/conversations/{task_id}`；无后端任务的空会话和演示会话只移除本地记录。删除当前会话后切换到其他会话，最后一个真实会话删除后提供可用的新对话。请求失败时保留条目与草稿，执行中或正在提交的会话不能删除。

后端在 `state/conversation-meta.json` 原子写入 `deleted_at`，不删除上传材料、生成文件、发布产物或数据库审计记录。会话列表过滤已删除任务，并通过 `deleted_task_ids` 清理其他标签页保留的旧本地缓存；旧标签页再次提交到已删除任务会被拒绝。删除与提交共享提交锁，持久执行锁和本机活动任务检查阻止删除正在运行的任务。无数据库迁移。

检查确认标题模型调用与标题 API 均已设置 60 秒上限，无自动重试；前端 65 秒中止为响应传输留出时间，失败保留首条消息的兜底标题。未改变主报告模型超时。

验证：会话删除、标题超时、卡片交互与持久检查点专项 43 项通过，1 项显式启用的 MySQL 集成测试跳过；3 项标题前端函数测试通过。浏览器测试覆盖取消删除、请求失败后保留、旧缓存同步、刷新、清缓存、删除当前会话、删除本地空会话与运行中保护，pageerror 为零。Ruff、JS 语法和 diff 空白检查通过。

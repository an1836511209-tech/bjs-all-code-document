# 北交互联项目全称与候选选择

选择“是，正在北交互联披露”后，卡片右侧显示项目全称输入框，placeholder 为“输入北交互联正在挂牌的项目全称”。全称必填；切换状态会隐藏输入框，草稿随当前问题保存，刷新可恢复。选择“不是”或“不确定”跳过财务查询。

后端将用户输入原样保存为当前任务的 `cbex_lookup`，查询包装器使用该全称覆盖模型参数。MCP 返回多个匹配项目时不再自动取最高分项目；返回候选并自动暂停 Agent，在前端列出项目名称、项目类型和信息披露截止日期。用户选中后点击“继续当前任务”，后端从待回答卡片中取得对应名称和 URL，再调用原 `query_cbex_listing_financials` 的 `detail_url` 分支直接提取详情页，不重新搜索。

候选新增可选 `disclosure_end_date` 字段，读取官网列表项目行内的披露截止日期或披露起止日期的末日，未披露时返回空字符串，卡片显示“未披露”。候选日期按项目行隔离，不使用成立日期等无关日期。

普通执行、持久检查点、问题恢复和工具结果缓存均接入候选选择：未回答前不执行依赖工具，选定 URL 后不会命中先前搜索阶段的缓存。同步修正 one-pager Skill 财务读取路径为 `annual/latest/detail_url`。

验证：48 项单元/交互/检查点回归通过，1 项需要显式启用的 MySQL 集成测试跳过；独立浏览器 fixture 验证右侧布局、全称必填、草稿恢复、候选元数据、选定 URL 及跳过分支，pageerror 为零。另读取官网公开列表核对“披露起止日期”结构；未执行真实项目财务生成全链路。

更新后重启 API 与 Data MCP，刷新控制台加载带版本号的新资源。无数据库迁移。

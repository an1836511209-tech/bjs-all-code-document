# test / UAT DMP 模拟接口、大报文与独立附件验收

日期：2026-10-31。

## 行为

新增独立标准库 HTTP 服务 `scripts.dmp_mock.server`，只允许 test/UAT。对当前 DMP 路径提供 GET/POST，校验测试 SHA1 签名、nonce/时间戳及网关 HMAC-SM3；返回现有业务字段，支持直接 JSON、body、data 三种对象包装。业务侧只增加显式 mock 模式、地址隔离和测试用途头，沿用原 HTTP、解包、清洗与 Excel 路径。

默认可匹配库 10,000 家机构、50,000 人。每家机构约 3,000 个标签，200 家原始响应超过 16 MiB，清洗后才通过 MCP 交付小型 XLSX。报告仍最多取 30 家，个人 count 为本页条数；独立附件仍只请求首批 200 家，不分页。测试机构名称带明确前缀。

报告与导出场景独立配置：正常、空表、脏数据、无效 JSON/字段、HTTP 错误、超时、首次失败和超过 64 MiB。大响应普通模式有预估 48 MiB 上限及并发限制，oversize 使用流式数据；诊断只保存最近 100 次有界元信息，不保留 token、签名或原始长标签。

## 接入

- test/UAT 的 DMP 配置默认指向模拟服务，并启用独立附件；生产环境 YAML 不变，缺省仍为真实模式。mock 模式强制使用公开测试凭据，不读真实 DMP/API 平台密钥；禁止连非白名单地址，不自动转发生产。
- `compose.dmp-mock.yaml` 为非生产覆盖文件，包含模拟器和独立 worker，共享当前环境的数据库配置及工作区。test/UAT 使用独立 Compose 项目、工作区和默认子网；同机部署可指定不同端口。
- Windows 与 Linux 的 `start-nonprod` 脚本构建并启动所需服务；`start-local.ps1` 增加模拟器及一键验收入口。
- 补齐镜像构建上下文中 uv workspace 必需的两个包的元信息/README；生产运行参数与默认业务端口保持原值。
- 不新增数据库迁移。新部署仍需已有数据库/MinIO及附件表，其他模型、画像、OCR、赛道标签依赖保持原环境配置。

## 验收方式

运行 `python -m scripts.dmp_mock.verify --iterations 100`。脚本不读 runtime.env，自动启动/关闭临时真实 HTTP/MCP 服务，用合成上下文和内存任务/对象存储替身完成重复导出、真实 XLSX 校验、10 任务入队、API 预览下载、失败保留报告与手动重试。完整使用说明见 [模拟器 README](../../scripts/dmp_mock/README.md)。

本次结果：

- 模拟接口专项 31 个不同用例通过（全量 30 项及新增密钥读取隔离用例已验证），原 Data MCP/配置 52 项及 Report Agent 附件/入口/配置 58 项通过，去重合计 141 项。
- 100 次真实 MCP 导出逐次校验 XLSX，10 个任务入队后按单并发交付，无标签串用；另验证默认大响应经真实 MCP/worker 协调器生成、预览和下载，以及首次 HTTP 500 后手动重试恢复。
- 默认大响应实测 18,029,610 字节，200 行 XLSX 11,623 字节，MCP 返回 JSON 约 16,084 字节。大报文不进入主报告工具结果。
- GET/POST 与三种响应包装、64 MiB 上限、超时、错误格式、HTTP 错误、个人分页统计、生产环境与非白名单地址拒绝、测试模式不读取真实密钥引用均通过。
- Ruff、两处业务 Python 模块 Mypy、PowerShell 解析、Compose test/UAT 配置与 diff 空白检查通过。

本机 Docker 引擎未启动，未实际构建/启动容器、未部署远程 UAT；仅做了 Compose 配置校验与本机独立 HTTP/MCP 实跑。临时测试服务自动关闭，用户现有业务服务未重启，生产配置未改动。

实际环境部署仍需在 Docker 引擎运行的宿主机执行非生产启动脚本；本地替身验收不等于真实 MySQL/MinIO 或生产网关联调。

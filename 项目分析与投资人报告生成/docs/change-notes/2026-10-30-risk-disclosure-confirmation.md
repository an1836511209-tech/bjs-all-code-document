# 一页纸非优质项目信息展示确认

识别到风险、瑕疵等非优质项目信息后，真实一页纸流程在大纲阶段暂停，展示「展示 / 不展示」卡片。卡片列出第三个介绍槽位中识别的风险摘要和材料摘录，并允许补充说明。未选择时前后端均拒绝继续；选择和补充说明持久保存到当前任务，刷新可恢复。

`check_one_pager_outline` 首次识别风险时返回 `question_request`，普通执行与持久检查点均将其作为真实执行边界，过滤同批次依赖工具调用。用户回答后继续同一任务，不重复确认。

内部事实识别 `has_risk_facts` 与展示选择 `include_risk_facts` 分离：选择展示时第三个介绍标题固定为「风险提示」；选择不展示时改用其他材料内容与标题，并在写作指令中排除这些风险事实。展示标志由后端覆盖模型入参，模型不能自行反转选择。渲染工具也检查风险标题与确认结果，阻止绕过确认或沿用相反选择的正文。未识别到风险时直接继续。

确认保存在 `state/interaction.json` 的 `risk_disclosure`，识别摘要和材料依据保存在 `risk_review`。未新增 MCP、数据库表或外部调用。风险事实识别仍由 Agent 根据材料完成，确认卡片控制报告展示。

验证：风险确认、大纲、业务类型、会话卡片、北交互联选择和持久检查点回归 54 项通过，1 项需显式启用的 MySQL 集成测试跳过。独立浏览器 fixture 验证展示/不展示、补充说明、必选校验、刷新恢复和无风险跳过，pageerror 为零；Ruff、JS 语法与 diff 空白检查通过。浏览器 fixture 未调用真实模型或发布 Word。

重启 Report Agent API，刷新页面即可使用；无需重启 MCP 或迁移数据库。

## 2026-10-22 同一次部署里，这些不是代码 bug

| 现象 | 判断 |
| --- | --- |
| `match_investors` 报 `ExceptionGroup` / TaskGroup | **是 bug**，见 [DMP 文档](2026-10-22-dmp-word.md) 第 1 节。不是模型上下文超限：工具在结果进入对话前就失败了 |
| 个人请求体永远是 `"limit": 1`，yaml 里已经写成 500 | **是 bug**，见该文档第 2 节。机构 `limit: 30` 看起来正常，是因为代码默认值恰好也是 30 |
| docx 机构表只有第一行，Markdown 里却有几十家 | **是 bug**，见该文档第 3 节。只更新 data-mcp 不会改变 report-agent 的解析器 |
| 命令行结果里「没有个人数量」 | **不是 bug**。数量在 `internal.individual_count`。当时值为 1，是上面的 limit bug |
| 整包更新后 30 行能画全，只换 data-mcp 后又剩一行 | **不是 data-mcp 把表削短**。同一份旧 report-agent：引用在表尾时保留全部行，引用插在每一行后面时只留第一行 |
| 干净地址 `/v1/ai-service/investment` 打不开 | **按设计如此**。必须从带前缀的地址进入；前缀不是登录鉴权 |

# NL2SQL Agent 测试工具

这是一个基于Streamlit构建的自动化测试工具，用于验证NL2SQL Agent的准确率和召回率。

## 功能特性

- 🔄 **自动化测试用例生成**: 自动遍历7张业务表，为每个有值字段生成测试用例
- 🧪 **批量测试执行**: 自动调用NL2SQL Agent接口，批量执行测试
- 📊 **结果分析**: 计算精确率、召回率和F1分数
- 🎯 **可视化展示**: 提供直观的测试结果展示和分析
- 📥 **结果导出**: 支持将测试结果导出为CSV文件

## 测试流程

1. **数据检查**: 自动检查7张表的所有字段是否有数据
2. **用例生成**: 为每个有值字段随机选择一条记录，生成测试问题和标准答案
3. **接口调用**: 将测试问题发送给NL2SQL Agent
4. **结果对比**: 对比Agent返回的结果与标准答案
5. **指标计算**: 计算精确率、召回率和F1分数
6. **结果展示**: 通过Web界面展示测试结果

## 测试用例生成规则

1. **字段筛选**: 排除`project_code`字段（目标查询字段）和系统字段（created_at、updated_at、id等）
2. **数据检查**: 只为有非空值的字段生成测试用例
3. **字段注释**: 自动获取数据库字段的中文注释，用于生成更自然的问题
4. **问题格式**: "请在{表名}中帮我找一下{字段注释}为{值}的项目"
5. **标准SQL**: `SELECT DISTINCT project_code FROM {table} WHERE {column} = '{value}'`
6. **随机采样**: 为每个字段随机选择一条记录的值
7. **值清理**: 自动过滤过长值（>100字符）和包含特殊字符的值，确保SQL正常执行
8. **长度限制**: 跳过值长度超过100个字符的字段，避免测试复杂度过高

## 评估指标

### 精确率 (Precision)
```
精确率 = |正确答案 ∩ Agent答案| / |Agent答案|
```

### 召回率 (Recall)  
```
召回率 = |正确答案 ∩ Agent答案| / |正确答案|
```

### F1分数
```
F1 = 2 × (精确率 × 召回率) / (精确率 + 召回率)
```

## 注意事项

1. **网络连接**: 确保能够访问数据库和Agent接口
2. **权限验证**: 确保数据库用户有读取权限
3. **接口限制**: 避免过于频繁的API调用，工具已内置延时控制
4. **数据量**: 如果表数据量很大，测试用例生成可能需要较长时间
5. **字段过滤**: 自动跳过系统字段（created_at、updated_at、id等）和有问题的字段
6. **值清理**: 自动过滤过长值和包含特殊字符的值，避免SQL语法错误

## 故障排除

### 数据库连接失败
- 检查网络连通性
- 验证数据库配置信息
- 确认数据库服务状态

### Agent接口调用失败
- 检查接口URL可访问性
- 验证Authorization Token
- 检查请求参数格式

### 测试用例生成失败
- 检查表是否存在
- 确认字段是否有数据
- 查看控制台错误信息

### 常见SQL错误
- **TIMESTAMP错误**: 系统会自动跳过created_at、updated_at等时间字段
- **保留字冲突**: 使用反引号包围字段名，如`usage`字段
- **特殊字符**: 自动清理包含单引号、换行符等特殊字符的值
- **值过长**: 限制测试值长度不超过100字符

## 📱 使用流程

### 基本测试流程
1. **启动应用**：`streamlit run nl2sql_test_app.py`
2. **生成测试用例**：自动扫描数据库，生成带注释的测试用例
3. **预览测试用例**：查看生成的问题和预期结果
4. **开始测试**：点击"🧪 开始测试"按钮启动自动化测试
5. **实时监控**：观看测试进度和每个案例的执行结果
6. **查看结果**：在"测试结果"和"测试详情"页面分析整体表现

### 高级测试控制
1. **暂停测试**：发现问题时点击"⏸️ 暂停"按钮
2. **问题分析**：查看已完成的测试结果，分析Agent表现
3. **重新测试**：对特定失败案例点击"🔄 重新测试"
4. **恢复测试**：修复问题后点击"▶️ 恢复"继续剩余测试
5. **导出数据**：将完整结果导出为CSV文件进行进一步分析

### 推荐工作流程
1. **小批量测试**：先生成少量测试用例进行初步验证
2. **问题发现**：发现问题时暂停测试，分析具体案例
3. **Agent优化**：根据测试结果优化Agent参数或提示词
4. **重复验证**：对问题案例重新测试验证修复效果
5. **全量测试**：确认无问题后执行完整测试集
